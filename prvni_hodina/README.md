# První hodina: Python, konzole a soubory

Z kořene repozitáře spusť `python3 spustit.py` a vyber **Python a konzole**.
Rozcestník obsahuje podrobný popis, studentské úkoly i přímo spustitelné akce.

Samostatné spuštění z této složky:

```bash
python3 zaklady_pythonu.py
python3 ukol_soubory.py
bash zaklady_konzole.sh
```

`zaklady_pythonu.py` ukazuje základní syntax bez další instalace. Souborový
program čte čísla ze sousedního `vstup.txt` a **přepisuje** `sude.txt`/`liche.txt`.
Průvodce Bash používá vlastní dočasnou cvičnou složku a ptá se na volitelné kroky.
Odpovědi lze zadávat i přes vstupní řádek centrálního spouštěče.

Windows materiály: `zaklady_powershellu.ps1` a `INSTALACE_WSL2_DEBIAN.txt`.
PowerShell skript spouštěj ve vhodném prostředí podle komentářů v jeho úvodu.
