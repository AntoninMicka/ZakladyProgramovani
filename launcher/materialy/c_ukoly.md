# Úkoly: jazyk C

## 1. Stejná úloha ve dvou jazycích

Porovnej proměnné, podmínku a cyklus v `zaklady_c.c` s první Python hodinou.
Napiš tři rozdíly v zápisu. Pak v obou programech změň stejnou vstupní hodnotu
a porovnej výsledek.

## 2. Pole a funkce

Přidej další ovoce do pole a uprav počet položek. Uprav funkci pozdravu a zavolej
ji dvakrát s různými jmény. Program musí projít překladem bez nových varování.

## 3. Rozdělení čísel s počítadly

Doplň do souborového programu počty sudých a lichých čísel. Ověř vstup 3, 8, 0, -5.
Výstupní soubory musí obsahovat stejné hodnoty jako Python verze a ve stejném pořadí.
Pozor: opětovné spuštění výstupní soubory přepíše.

## 4. Chybové situace

Vyzkoušej chybějící vstupní soubor a řádek s textem místo čísla. Vysvětli,
jak program chybu pozná a co uživateli vypíše. Nemaž si původní vstup bez zálohy.

## Odevzdání

Odevzdej upravený zdroj a krátký zápis: jak jsi program spustil, jaká data jsi
použil, co se mělo stát a co se skutečně stalo. Samotný obrázek úspěšného překladu
neověří, že program správně rozděluje čísla.
