# Python a práce s konzolí

První sada cvičení propojuje čtení zdrojového kódu se skutečným výstupem programu.
Začni akcí **Spustit základy Pythonu**. Program nepotřebuje vstup z klávesnice
ani další knihovny; postupně vypíše devět témat.

## Co se naučíš

Proměnné a datové typy, výpočty, podmínky, seznamy, cykly, funkce, slovníky,
množiny a převod textu na čísla. Komentáře ve zdroji vysvětlují jednotlivé kroky.
Nejlepší postup je nejdřív odhadnout výsledek, potom program spustit a až nakonec
porovnat svou předpověď se skutečností.

## Programy a ovládání

- **Základy Pythonu** spustí `prvni_hodina/zaklady_pythonu.py`.
- **Rozdělení čísel** načte `vstup.txt` a přepíše výstupy `sude.txt` a `liche.txt`.
  Pořadí čísel se zachovává. Nula patří mezi sudá čísla, záporná čísla se také třídí.
- **Bash / Git** vytvoří samostatný cvičný adresář v `/tmp`. Ukáže složky,
  kopírování, přesměrování a lokální historii Git. Odpovědi na otázky zadávej do
  vstupního řádku spouštěče a stiskni Odeslat. Případné klonování z internetu je
  volitelný krok uvnitř průvodce, ne automatická akce spouštěče.
- **PowerShell** vyžaduje nainstalované `pwsh` nebo `powershell`. Bez něj si můžeš
  jeho komentovaný zdroj přečíst. Materiál je určený hlavně prostředí Windows.

## Doporučený postup

1. Spusť základy a otevři vedle výpisu zdroj přes **Zobrazit zdrojový kód**.
2. Udělej malou změnu, například jiný věk nebo další ovoce, a soubor ulož ve svém editoru.
3. Spusť program znovu. Pracovní adresář zvolí spouštěč automaticky.
4. Přejdi na souborový úkol a ověř vytvořené soubory přes **Otevřít složku**.
5. Teprve potom vyzkoušej konzoli a historii Git.

## Co musí být připravené

Python 3 je zároveň nástrojem pro spuštění tohoto rozcestníku. Základní Python
cvičení další balíčky nepotřebují. Bash část potřebuje Bash a Git. Instalační
průvodce WSL je v `prvni_hodina/INSTALACE_WSL2_DEBIAN.txt`.

Úspěšný výsledek není jen zelené „Dokončeno“: umíš vysvětlit, proč program vypsal
právě tato čísla a proč se nula zapsala do souboru sudých čísel.
