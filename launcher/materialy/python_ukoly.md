# Úkoly: první kroky s Pythonem

## 1. Odhadni výsledek

V `zaklady_pythonu.py` změň věk a příznak studenta. Před spuštěním napiš na papír,
která větev podmínky se provede. Ověř svůj odhad alespoň pro tři kombinace.

## 2. Vlastní seznam a funkce

Přidej do seznamu ovoce dvě další položky. Uprav funkci pozdravu tak, aby vypsala
tvoje jméno. Vysvětli rozdíl mezi číslem položky od jedné a indexem seznamu od nuly.

## 3. Souborové cvičení

Pro vstup `3`, `8`, `0`, `-5` na samostatných řádcích ověř výsledek:

- `sude.txt`: 8 a 0;
- `liche.txt`: 3 a -5.

Rozšiř program o výpis počtu sudých a lichých čísel. Pořadí nesmíš změnit.
Nakonec musí součet obou počtů odpovídat počtu vstupních čísel.
Souborový program při spuštění přepíše své dva výstupy.

## 4. Co když je vstup špatně?

Zkus prázdný řádek a slovo místo čísla. Přečti chybovou zprávu. S učitelem navrhni,
zda takový řádek přeskočit, nebo program srozumitelně ukončit. Svou volbu vysvětli.

## 5. Konzole a Git

Spusť průvodce Bash, vyzkoušej příkazy a prohlédni dva vytvořené commity.
Ve cvičné složce změň textový soubor a vysvětli rozdíl mezi změnou na disku,
připravenou změnou (`git add`) a uloženým commitem.
